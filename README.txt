每日探索歌单
============

作者：松茸

一个读懂你网易云口味、每天帮你挖新歌的小工具。
它会刻意避开你听过的歌、歌手、专辑，从 16 个曲风池里
挑出你没听过但大概率会喜欢的新歌，并一键建歌单到你的账号。

────────────────────────────
快速开始
────────────────────────────
1. 双击 start.bat（会自动打开浏览器 http://localhost:8721）
2. ① 生成歌单：填「我喜欢的音乐」歌单链接或 id
   （扫码登录后可自动带出，不用手填）
3. ② 登录：点「生成登录二维码」，用网易云 App 扫码
4. 点「生成今日 15 首」
5. 不满意就点每首歌右下角「换一首」，或顶部「换一批」
6. 点「创建到网易云」，得到官方链接 / 分享口令

────────────────────────────
文案（可选）
────────────────────────────
默认展示每首歌的歌词摘录。
想要 AI 梗概，去「③ 文案设置」选「AI 梗概」，填 LLM key：

- 推荐平台：硅基流动 siliconflow.cn（注册送 14 元额度）
- 接口地址：https://api.siliconflow.cn/v1
- 模型名：deepseek-ai/DeepSeek-V3.2

填完点「测试连接」验证，再点「保存设置」。

────────────────────────────
说明
────────────────────────────
- 全程本地运行，数据不出你的电脑
- 登录态和配置只保存在本机 data 目录，不会上传
- 每天歌单会跟随你最近的听歌口味动态变化
- 基于网易云非官方接口，仅供个人自用，请勿公开商用

祝听歌愉快 🎧
